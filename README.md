# 📝 Prompt Manager

App per salvare, organizzare e riutilizzare i prompt per le AI (ChatGPT, Claude, ecc.).
Unisce una libreria di prompt e un overlay sempre in primo piano con i prompt a portata di clic.

**Apri l'app:** https://gabriele-errico.github.io/prompt-manager-app/ (dopo aver attivato GitHub Pages)

## Funzioni
- **Libreria**: aggiungi, modifica, elimina e copia i prompt; categorie (crea, rinomina, elimina); preferiti ⭐
- **Ricerca** per titolo, contenuto o categoria
- **📌 Overlay**: finestra compatta sempre in primo piano con i preferiti e dei box di testo liberi
  (Copia, Pulisci, Salva nella libreria). Sempre in primo piano su Chrome/Edge desktop.
- **Backup**: Esporta/Importa in JSON, con promemoria se non esporti da 7+ giorni
- **Librerie di prompt** esterne collegate nella barra laterale
- Tema chiaro/scuro, scorciatoie da tastiera (`H` per l'elenco), uso offline, installabile come app (PWA)

## Librerie di prompt collegate
Raccolte pubbliche da cui prendere spunto (link anche nella barra laterale dell'app):
- [prompts.chat](https://github.com/f/prompts.chat) – la raccolta pubblica di prompt più grande
- [PromptLibrary](https://github.com/MrXie23/PromptLibrary) – prompt in più lingue, divisi per categoria
- [The Focus AI prompt-library](https://github.com/The-Focus-AI/prompt-library) – libreria con PWA e CLI
- [prompt-library](https://github.com/thibaultyou/prompt-library) – prompt curati da eseguire da riga di comando
- [Biblioteca de prompts para estudiar con IA](https://github.com/hhkaos/biblioteca-de-prompts-para-estudiar-con-ia) – prompt per studiare (in spagnolo)

## Come si usa
Apri `index.html` (o `prompt-manager-app.html`) nel browser. Per l'installazione come app e
l'uso offline la pagina va servita via `https` (es. GitHub Pages) o da `localhost`.

> I dati sono salvati solo nel browser in uso: esporta regolarmente un backup.
